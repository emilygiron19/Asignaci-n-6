Conceptos básicos del desarrollo web

¿Qué es una página web?

Una página web es un documento digital escrito en HTML que se puede ver desde un navegador (Chrome, Firefox, Edge, etc.). Puede contener texto, imágenes, videos, audio, enlaces y formularios. Un conjunto de páginas relacionadas, que comparten un mismo dominio, forma un sitio web.

¿Cómo funcionan las páginas web?

Las páginas web funcionan con el modelo cliente-servidor:

1. El cliente hace una solicitud

Cuando escribes una dirección (URL) en el navegador, este envía una solicitud al servidor donde está guardada la página.

2. El servidor responde

El servidor busca los archivos pedidos (HTML, imágenes, etc.) y los devuelve al navegador mediante el protocolo HTTP o HTTPS.

3. El navegador muestra la página

El navegador interpreta el código HTML recibido y lo convierte en la página que ves en pantalla.

Tipos de páginas web

Páginas estáticas

Muestran siempre el mismo contenido a todos los visitantes. Están hechas con archivos HTML ya escritos y solo cambian si el desarrollador las edita.
Son rápidas, sencillas y baratas de publicar.

Páginas dinámicas

Generan su contenido al momento de la solicitud, normalmente usando un lenguaje del lado del servidor y una base de datos. Pueden mostrar información distinta según el usuario, la hora o las acciones realizadas.
Ejemplos: redes sociales, tiendas en línea, portales de noticias.

Diferencia entre una aplicación web y un sitio web

Sitio web

Su objetivo principal es informar. El usuario lee y navega el contenido, con poca interacción. Por ejemplo, la página de una universidad o un blog.

Aplicación web

Su objetivo principal es que el usuario realice tareas: iniciar sesión, procesar datos, comprar, editar documentos, etc. Requiere más interacción y casi siempre usa un servidor y una base de datos. Por ejemplo, un correo electrónico en línea o una plataforma de banca en línea.
